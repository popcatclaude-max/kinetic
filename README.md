# Kinetic

Interactive live wallpapers for Windows: animated scenes, 3D anime and landscape pictures that move with your mouse, day and night versions, and more.

**Download:** get `Kinetic-Setup-x.y.z.exe` from the [latest release](https://github.com/popcatclaude-max/kinetic/releases/latest). Kinetic updates itself after that.
